# Lucky 下樓梯

像素風的「小朋友下樓梯」小遊戲，主角是小紅龍 Lucky。

## 怎麼玩

- 左右移動，踩著階梯一路往下，別碰到天花板的尖刺，也別掉出畫面
- 電腦：← → 或 A D 移動，P 暫停，Enter 再玩一次
- 手機：按住畫面左半邊或右半邊，或用下方的 ◀ ▶ 按鈕

## 城市

| 城市 | 特殊機關 |
|---|---|
| 美國・洛杉磯 | 地震來襲時，所有階梯會左右晃動 |
| 西班牙・巴塞隆納 | 聖家堂工地的吊車鋼樑會左右移動 |

## 階梯種類

- 能量板：回復 1 點生命
- 雷射尖刺：扣 5 點生命
- 輸送帶：把你往一邊推
- 跳躍板：把你彈高高
- 全息板：踩上去一下就消失

排行榜記錄在玩家自己的瀏覽器裡，兩個城市分開記前十名。

整個遊戲只有一個 `index.html` 檔，不需要安裝任何東西。
